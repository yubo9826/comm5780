# Felix's Digital Media Portfolio

A small personal website about my Digital Media studies at the University of Leeds, my current modules, and everyday life in Leeds.

## Pages

- **Home** (`index.html`) — A short introduction, current modules, and personal interests.
- **Leeds** (`leeds.html`) — An introduction to the University of Leeds campus and a gallery of everyday photos.

## Built with

- HTML
- CSS

The site is responsive and does not require a build step.

## Run locally

Open `index.html` in a web browser.

## Images

- Campus photos are credited to the [University of Leeds self-guided campus tour](https://spotlight.leeds.ac.uk/campus-tour/).
- Everyday photos were taken by Felix.

## Project files

- `index.html` — Home page
- `leeds.html` — University and everyday-life page
- `style.css` — Site styles
- `assets/everyday/` — Everyday-life photos
