# Week 6: photo classification pilot and record tools

Created 7 November 2026 for the COMM5780M identity and algorithmic identity workshop.

This is preparation and a small pilot, not a completed 32-person social-media study. No friends' social posts or personal advertising profiles are included.

The pilot takes the first five photos in each of the three chapters of Felix's existing public photo journal (15 photos total). It uses the visible images, captions and chapter context. Each image receives one category under the workshop's original 13 categories, and one category under an expanded scheme that adds Travel & sightseeing and Food & drink. Coding suggestions and artifacts were prepared with AI assistance; alternative labels and reasons remain visible for review. These labels describe a curated set of photographs, not a person's whole identity or a platform's actual profile.

Files:
- pilot.json / pilot.csv: photo-level coding decisions and alternatives.
- counts.csv / category-comparison.png: comparison of the two coding schemes.
- anonymous-post-template.xlsx: blank 32-person × 15-post record sheet, with category dropdowns and summary counts. It contains no observed social-post records. It is an Excel alternative, not the web tool's CSV import format.

The web tool at ../../identity-lab.html provides a separate 480-slot anonymous record form, CSV import/export and a two-category scatter plot. Only people with all 15 posts coded enter the plot. User records stay in the browser's current page memory and disappear on refresh; export to retain a copy.
